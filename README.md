# 🌙 BetterRest — когда пора спать?

Во сколько лечь, чтобы проснуться к нужному времени? **BetterRest** — учебное iOS-приложение на SwiftUI, которое использует модель Core ML для расчёта примерного времени отхода ко сну.

## Как это работает

1. Выбери время, когда хочешь проснуться.
2. Укажи желаемую продолжительность сна — от 4 до 12 часов с шагом 15 минут.
3. Выбери количество чашек кофе в день — от 0 до 10.
4. Нажми **Calculate**: приложение покажет расчётное время в сообщении.

Модель получает время подъёма, продолжительность сна и количество кофе, а затем приложение вычитает предсказанную продолжительность сна из времени подъёма. При ошибке расчёта показывается сообщение об ошибке.

> Результат — учебный прогноз модели, а не медицинская рекомендация или гарантия качества сна.

## Что я здесь изучаю

- **SwiftUI**: `NavigationView`, `Form`, `DatePicker`, `Stepper`, `Picker` и `alert`.
- **`@State`** и привязки для работы с пользовательским вводом.
- **Core ML**: загрузку модели, передачу параметров и обработку результата или ошибки.
- **Date и Calendar**: преобразование времени подъёма и форматирование результата.
- Основы работы с моделью табличной регрессии в **Create ML**.

Интерфейс приложения — на английском языке.

## Запуск

1. Склонируй репозиторий или скачай его через **Code → Download ZIP**:

   ```bash
   git clone https://github.com/nyuchosee/BetterRest.git
   ```

2. Открой в Xcode **`BetterRest✅/BetterRest.xcodeproj`**.
3. Выбери схему **BetterRest** и симулятор iPhone, затем нажми **⌘R**.

В настройках проекта указаны режим языка **Swift 5** и **iOS 15.0**; проект создан в Xcode 13.1. В более новом Xcode настройки могут потребовать обновления.

## Что находится в проекте

```text
BetterRest✅/
├── BetterRest.xcodeproj
├── SleepCalculator.mlmodel   # Модель, используемая приложением
├── BetterRest.mlproj/         # Проект Create ML
└── BetterRest/
    ├── BetterRestApp.swift    # Точка входа
    ├── ContentView.swift      # Форма и расчёт
    └── Assets.xcassets
```

Готовая модель `SleepCalculator.mlmodel` входит в репозиторий. Проект Create ML ссылается на CSV-файл по локальному пути исходного компьютера; самого CSV в репозитории нет, поэтому для повторного обучения потребуется найти исходные данные и указать их заново.
